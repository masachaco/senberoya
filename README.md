# センベロ屋

サイゼリヤで食べたい料理を選ぶと、残りの予算でいちばん多く飲めるワインの頼み方（グラス・デカンタ小/大・マグナム）を計算する非公式ツールです。

公開ページ: https://masachaco.github.io/senberoya/

## 公開方法

`index.html` 1枚だけの静的ページです。GitHub Pages の設定で「Deploy from a branch」→ `main` / `(root)` を選ぶと公開されます。

## 大事なおことわり

- このツールは、たくさん飲むことを勧めるものではありません。飲み過ぎには気をつけてください。
- このツールの計算結果をもとにした注文や飲酒で起きたことについて、作者は責任を負いません。
- 価格と注文番号は作成時点のデータです。実際のメニューとずれていることがあるので、注文する前に必ず店のメニューで値段を確かめてください。
- サイゼリヤ非公式のツールです。お酒は20歳になってから。
